# Scalpels guides: companion code

Code that goes with the guides at [scalpels.app/docs](https://scalpels.app/docs?type=guides).

Each guide has its own branch, named after the guide's slug. `main` holds only this README.

| Guide | Branch |
| --- | --- |
| [Continuously improve your software with Solo, Hone, Reel and Wake](https://scalpels.app/guides/continuously-improve-your-software) | [`continuously-improve-your-software`](../../tree/continuously-improve-your-software) |

To use one, clone the branch you need:

```shell
git clone --branch continuously-improve-your-software --single-branch \
  https://github.com/artisan-build/scalpels-guides.git improvement-loop
```
